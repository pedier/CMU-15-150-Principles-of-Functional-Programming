# CMU 15-150: Principles of Functional Programming

Programming assignments from Carnegie Mellon University's [15-150 course](https://www.csd.cmu.edu/course/15150/s26), Spring 2026, written in Standard ML.

Assignments: `basics`, `induction`, `polysort`, `datatypes`, `hofs`, `cps`, `regex`, `exceptions`, `modules`, `sequences`, `lazy`, and `imperative`.

Includes implementations, tests, course libraries, and ML build definitions. Use the per-exercise `smlnj` launchers in the course's SML/NJ and Molasses environment. Type-error exercises and sandbox scaffolds are retained where relevant.
